# Pro Billiards 2D

A self-contained Flutter starter project for an offline 2D pool game.

## Import into Klencod IDE
1. Extract `pro_billiards_2d.zip`.
2. Import/open the `pro_billiards_2d` folder as a Flutter project (or use the IDE's ZIP import if available).
3. Run `flutter pub get` / Pub Get.
4. Build and run on Android.

## Notes
- This starter has no third-party package dependencies and is designed to run offline.
- It includes a custom-painted pool table, ball rendering, basic collisions, pockets, aiming interaction, scores, and a simple computer shot.
- It is a starting prototype, not a finished commercial-grade billiards simulation. Test in the target Klencod/Flutter version and refine physics and touch controls.
